# NOVA

NOVA is a lightweight Android agent.

Version 0.1 focuses on:

- Low RAM usage
- Native Android implementation
- Command routing
- Skill registry
- Persistent local skill storage
- Safe application launching
- Simple agent UI

No local large language model is included.

Future versions can add:

- Screen observation
- Better intent understanding
- Skill learning
- Cloud AI integration
- Agent planning
- Safe Android actions
